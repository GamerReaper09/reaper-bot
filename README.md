# Reaper Bot
Reaper bot is my first slack bot with a few random (maybe even useful?) commands.
![Picture of the bot](./BotExample.png)

You can try the bot in the official Hack Club slack [here](https://hackclub.enterprise.slack.com/archives/C0P5NE354).

## Commands
| Command                        | Description                              |
|--------------------------------|------------------------------------------|
| /reaper-bot-ping               | Pings the bot                            |
| /reaper-bot-catfact            | Show a random fact about cats            |
| /reaper-bot-joke               | Tells a random joke                      |
| /reaper-bot-dog                | Shows a picture of a random dog          |
| /reaper-bot-daysuntilchristmas | Shows the amount of days until christmas |
| /reaper-bot-calc               | A simple text calculator                 |
